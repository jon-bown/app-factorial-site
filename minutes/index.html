Minutes

Put minutes toward the things that matter. Set a time goal for anything you want to practice, time each session with a built-in stopwatch, and watch your progress rings fill up.

Minutes is an early concept app and isn't available in the App Store. The full source code is on GitHub.

View the source on GitHub

How it works

Set a goal

Give each goal a name, a color and a target number of minutes, then choose whether it repeats daily, weekly or monthly and when it starts.

Progress rings

The Summary screen shows every goal as its own colored ring, nested together so you can see all of your progress at a glance.

Time your sessions

Open a goal to start, pause and save sessions with a built-in stopwatch, and a progress bar shows how close you are to your target.

Stays on your device

Goals and logged time are saved locally with Core Data. No account needed.

Built with

Written in Swift with SwiftUI, with goals stored on the device using Core Data.
